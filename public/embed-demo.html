Some Unrelated Static Website

This page shows the widget running outside the main site. It's plain HTML, and the chat bubble in the bottom-right corner is powered by the exact same /api/chat backend and knowledge base as the main site.

How it's embedded

<script
  src="/widget.js"
  data-api="/api/chat"
  data-brand="AquaFix Plumbing"
></script>

In a real client delivery, data-api would point at their deployed backend URL and data-brand would match their business name — the client pastes one script tag into their existing site (WordPress, Shopify, Webflow, static HTML, anything) and gets a working AI support widget.
